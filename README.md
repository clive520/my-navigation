# My Navigation

個人導覽網站，集中管理所有製作的網站連結。

## 技術棧

- React 18 + Vite
- Tailwind CSS
- Cloudflare Pages
- Cloudflare D1 (SQLite)
- Cloudflare R2
- Hono (API 框架)

## 功能

- 卡片式導覽展示
- 搜尋 + Tag 篩選
- 管理後台（密碼保護）
- 圖片上傳
- 拖拽排序

## 開發

```bash
# 安裝依賴
npm install

# 本地開發
npm run dev

# 建構
npm run build

# 部署
npm run deploy
```
